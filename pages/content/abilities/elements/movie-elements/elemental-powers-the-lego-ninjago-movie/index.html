Overview

“Your call signs are not just cool names. They are the elemental powers you were all born with.”
— Wu to the Secret Ninja Force, The LEGO Ninjago Movie

Elemental Powers are abilities used by Wu and the Secret Ninja Force. They can be accessed by finding inner peace.

Elements

Elements[]

Fire[]

Fire is an element used by Kai. It gives its user the power to create and manipulate flames. It is generally associated with the color red.

Lightning[]

Lightning is an element used by Jay. It gives its user the power to create and manipulate electricity. It is generally associated with the color blue.

Earth[]

Earth is an element used by Cole. It gives its user the power to create earthquakes and shock waves. It is generally associated with the colors black and brown.

Ice[]

Ice is an element used by Zane. It gives its user the power to manipulate cold and ice. It is generally associated with the color white.

Water[]

Water is an element used by Nya. It gives its user the power to create and manipulate water. It is generally associated with the colors light blue.

Creation[]

Creation is an element used by Wu. Unlike the TV series version, it allows the user to control the other five elements stated above.

Green[]

Green is an element used by Lloyd. Green represents life and allows the user to connect with nature and all living things. It is generally associated with the color green.

Surprise[]

Surprise is an element used by the Fuchsia Ninja. It gives its user the power to manipulate surprise. It is associated with the color fuchsia.

Destruction[]

Destruction is an element used by Garmadon.[1] It is unknown what abilities it gives the user or what color it is associated with.

Trivia

Trivia[]

  • It's unknown if Elemental Powers are passed down genetically as they are in the TV series, though Wu does say the ninja "were all born with" their powers.
  • Although Garmadon has the element of Destruction like his TV series counterpart, he never used it in the movie.[1]
