Overview

This article is about the Legacy set. For the original set, see 70676 Lloyd's Titan Mech. For the actual mech, see Titan Mech.

71860 Lloyd's Titan Mech is a Ninjago: Legacy Wave 7 set that released on March 1, 2026. It includes Legacy ZX Lloyd, as well as exclusive figures Grimfax and Hibernus.

LEGO.com description

LEGO.com description[]

Teen boys, teen girls and nostalgic ninja fans ages 14 and up can celebrate the 15th anniversary of the LEGO® NINJAGO® TV show with this highly impressive and feature-packed mech toy. The LEGO NINJAGO Lloyd’s Titan Mech 15th Anniversary (71860) action figure set is an upgraded version of the fan favorite original Lloyd’s Titan Mech (70676) model. This mech toy features several posable body parts including wings, legs, feet, arms and shoulders and a cockpit for a minifigure. It also comes armedwith a large sword and, for the first time ever, a large shield that can be repurposed and placed on the back as a pair of wings. The model building kit comes with 3 minifigure characters, Lloyd and Grimfax from the TV show, plus a collectible elemental Master of Ice on a stand. Ninja fans can build the playset with confidence using the LEGO® Builder app – zoom, rotate in 3D and track progress with easy-to-follow digital instructions. Building set contains 1,293 pieces.

  • ACTION FIGURE SET – Lloyd’s Titan Mech 15th Anniversary (71860) building set for boys, girls and nostalgic fans ages 14 and up to celebrate 15 years of the LEGO® NINJAGO® TV show

  • GIFT FOR TEEN BOYS AND GIRLS – This NINJAGO® toy provides a rewarding build-and-play experience and is a ninja gift for teenagers and nostalgic NINJAGO fans

Trivia

Trivia[]

  • The set is a remake of 70676 Lloyd's Titan Mech.
  • Grimfax and Hibernus are both exclusive to this set.
  • Despite over five years of non-use in sets, the mold for the 2019 Blizzard Samurai helmet piece for Grimfax was able to be brought back in dark blue as the mold was more recently used in prototype Crystalized sets.[2]
  • The back portion of the mech is compatible with 71821 Cole's Titan Dragon Mech.[3]
