Overview

“The aftermath of Motion, the air itself exhaling. A release that can move others in its wake.”
— Glen Lakin on Bluesky[1]

Shockwave is an Elemental Power in the Merged Lands that is derived from the Source Dragon of Motion.[1] It is associated with the colors indigo and lavender.

Users' abilities

Users' abilities[]

  • Seismokinesis - The user can create and manipulate shockwaves.
    • Seismokinetic Attacks - The user can attack with shockwaves.
      • Seismokinetic Blast - The user can create a blast of shockwave-like energy.
        • Elemental Negation - The user can negate elemental powers to avoid being affected by them using their shockwave blasts.
      • Seismokinetic Beam Emission - The user can project beams of shockwave-like energy.
    • Seismokinetic Flight - The user can propel themselves up or forward using shockwaves.
    • Impulsukinesis - The user possesses the ability to manipulate propelling force, allowing them to push things away from specific points.
      • Energy Accumulation - The user can accumulate energy (personal, kinetic, etc.) from any source for any purpose.
      • Propulsive Blast - The user can release propulsive energy/matter over a specific target area, causing great damage and/or delivering great shock waves of pure force.
      • Forceful Propulsion - The user can propel themselves by pushing off of anything, as seen when Zeatrix used her power to lift herself off the ground.
      • Charging - The user can charge an attack as seen when Zeatrix used it with Surface Tension.
    • Concussive Force - The user can deliver an impact of concussive force.
      • Concussive Blast - The user can release concussive energy/force over a specific target area.
      • Concussive Beam Emission - Users like Zeatrix appear to be able to release concentrated beams of concussive force.
    • Elemental Combination - The user appears to be able to combine Shockwave with other Elemental Powers, such as when Zeatrix merged it with Surface Tension.
      • Elemental Bomb Generation - By combining Shockwave with Surface Tension, the user can create an elemental bomb, as shown by Zeatrix.
