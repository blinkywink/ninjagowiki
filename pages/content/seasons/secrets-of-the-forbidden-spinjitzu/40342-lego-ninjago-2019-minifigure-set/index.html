Overview

40342 LEGO NINJAGO 2019 Minifigure Set is a Ninjago - Secrets of the Forbidden Spinjitzu set that released in July 2019. This set includes a Legacy (dragon) Kai minifigure with the Summer 2019 mask and armor piece, Pyro Destroyer, a new Blizzard Archer minifigure, and Clutch Powers. This set also includes weapons for each character and a mini-build.

Trivia

Trivia[]

  • Despite predating Ninjago, this is the first appearance of Clutch Powers in any LEGO set.
  • This set contains figures from both Season 10: March of the Oni and Season 11: Secrets of the Forbidden Spinjitzu, though Kai's Legacy Minifigure uses his Season 11 armor and mask. The previous Minifigure sets usually focused on only one season.
  • This is the second set to feature the LEGO Batman Movie utility belt piece, the first being 70651 Throne Room Showdown with Skylor.
