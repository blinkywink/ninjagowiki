Overview

"I know it's a scroll, but what does it say? It's written in chicken scratch."
The subject of this article has never been officially released in English.
The name for this page was determined by directly translating the original German title.


Ninjago: Legacy HERO is a Ninjago-themed magazine line released across various European countries. It's similar to the main Ninjago: Legacy Magazine line in that it draws from multiple aspects from across Ninjago's run, but only focuses on one particular hero for each issue.
