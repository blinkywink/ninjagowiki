This page will outline what is expected for each Character page.

Which characters should have pages?

Which characters should have pages?[]

  • All named characters should have pages.
  • All characters who exist in minifigure form should have pages.
  • All characters who are relatives of known characters should have pages.
  • Speaking characters should have pages unless they are generic citizen designs or have no significant relation to the story or any other existing character.
  • All characters from other LEGO themes should have pages.
What should the pages be named?

What should the pages be named?[]

Generally, character pages should include both the character's first and last name in the title, with some examples being Brad Tudabone and Jacob Pevsner. However, major characters' pages such as Jay and Lloyd should simply be the characters' first names, because this allows for easier linking on most pages.

Introduction[]

Quote[]

Another part of the character page is the {{Quote}} template. For the quote itself, it should describe the character's history, role, personality, or motivations. It should not be something random that leaves the reader confused. For example:

“Tes neeb sah part eht.”
— Mr. E's message, "Dead Man's Squall"

While this is something Mr. E said, the quote is really vague and can make readers scratch their head unless you can describe the situation. Even when you describe the quote, it defeats the whole purpose of having a quote in the first place.

Also, the quote should explain the character's motivations and not just a short description about the character's function, as this can be ascertained from the opening paragraph, but the motivations cannot. For example:

“Benthomaar, the King's son. His... adopted son.”
— Benthomaar to the ninja, "Escape from Merlopia"

While the quote explains Benthomaar's function as Trimaar's son, the same information is also written in the opening paragraph of his page, which means that it defeats the whole purpose of having a quote in the first place.

Moreover, the quote can be said from another character and doesn't have to come from the character you're editing.

A voice recording of the quote can also be added to the page, being a part of the Quote template at the end, using this format: 

[[File:<name>|noicon|300px|right]]

Infobox[]

After creating the page, please use the {{Character}} infobox and fill out the necessary information about the character in the spaces provided.

  • color - This field should match the physical appearance of a character. If the character is currently unknown, please leave it grey.
  • image - If you wish to change the infobox image, users may not add an image to the infobox and instead must suggest it by making a proposal. This includes character pages being created for the first time. Until an image is decided, this file will serve as a placeholder. This field should be an image of the character in the Ninjago series. It is also possible to have an image from other official media if the character has not appeared yet in the TV series. Furthermore, the image may be cropped to show the character while headshots are prioritized. The image should also not be of poor quality and should not have a watermark. If there is no image for the character, please add this file.
  • species - This field should include all the classifications the character is affiliated with.
  • affiliation - This field should list all the groups and/or businesses that the character is officially a part of or a major ally of said group.
  • occupations - This field should list all the jobs the character had or currently has.
  • home - This field should list the character's home realm or homeland. If a character is deceased or undead, their afterlife realm will also be listed.
  • favweapon -This field should list all of the weapons used by the character.
  • element - If a character is an Elemental Master, their Elemental Power should be listed in this field. This includes all Elemental Powers, current and former, stolen or used. If the character only obtained a power through possession or a tool, do not include it.
  • first appearance - This field lists the first appearance a character makes in the series. If they appear in a set, it should be placed below. Meanwhile, if a character never appears, the episode they were mentioned in can be listed. An example is with Atta the Ratta who was mentioned "The Meaning of Victory."
  • latest appearance- This field should list the latest appearance of the character. If they appeared in a set, it should be placed below. If the character only appeared in one episode, please do not fill out this field. If they only appeared in one set, the set should be included.
  • status - This field should indicate a character's current condition. For consistency's sake, please use "Alive" if they are still alive, "Unknown" if their fate are unknown and "Deceased" if they are dead. Other words to describe different situations will be discussed within the community.
  • family - If a character's family has been mentioned in the series, it should be included here. This field should not include love interests (e.g. Jay and Nya, Kai and Skylor, P.I.X.A.L. and Zane, etc.)
  • relationship - If a character is or was in a non-married relationship with another character, it should be included here. This field should not include love interest. The term used to describe the relationship should preferibly reflected on the character's circumstances (the term "boyfriend" or "girlfriend" usually used for younger characters, while "partner", "lover" or occasionally "co-parent" usually used for older people).
  • voice actor - This field should have the character's voice actor. If the character changed his voice under certain circumstances (for example through shapeshifting), the voice actor of the character to which the character has changed should also be listed.

If the page is about more than one character (a group of species) then the {{Organization}} is used with the following information provided.

  • color - This field should match the physical appearance of a character. If the character is currently unknown, please leave it grey.
  • image - If you wish to change the infobox image, users may not add an image to the infobox and instead must suggest it by making a proposal. This includes character pages being created for the first time. Until an image is decided, this file will serve as a placeholder. This field should be an image of the character in the Ninjago series. It is also possible to have an image from other official media if the character has not appeared yet in the TV series. Furthermore, the image may be cropped to show the character while headshots are prioritized. The image should also not be of poor quality and should not have a watermark. If there is no image for the character, please add this file.
  • species - This field should only be used if the page is about a group, if there are no named members/leaders who have their own pages, and if all members are the same species.
  • leader - This field should include all leaders of the groups.
  • members - This field should include all current members of the group.
  • past members - This field should include all past members of the group, do not use this field for all members if the group has disbanded.
  • nationality - This field should include the realm or land the group was founded in. If the page is for a species, it should list the realms or lands of origin of the animal.
  • affiliation - This field should list all the groups and/or businesses that the character is officially a part of or a major ally of said group. On some occasions, the group could be affiliated to a singular character.
  • enemies - This field should include all enemies of the group.
  • element - This field should include all elements the users have used while being a part of the group. If the characters only obtained a power through possession or a tool, do not include it.
  • founded - This field should include when the group was founded. In-universe events are encouraged as indicators, although seasons of episodes can be used if not possible.
  • disbanded - This field should include when the group was disbanded.
  • base - This field should list all the locations that the group has used as a base of operations. Do not use this field if the only base is identical to the nationality.
  • status - This field should indicate the groups current condition. For consistency's sake, please use "Alive" or "Active" if they are still alive or active, "Unknown" if their fate are unknown, "Deceased" if if it is a species and all members are dead, "Near-exinction" if the amount of members is too low to repopulate. Do not use the field if the group has disbanded, as the disbanded field would be already used above. Other words to describe different situations will be discussed within the community.
  • family - This field should only be used if all members of the group or species share the same family member.
  • first appearance - This field lists the first appearance the group or a current member makes in the series. If they appear in a set, it should be placed below. Meanwhile, if group or species never appears, the episode they were mentioned in can be listed. An example is with Swamp Dragons who were mentioned "The Power Within."
  • latest appearance- This field should list the latest appearance of the character. If they appeared in a set, it should be placed below. If the group only appeared in one episode, please do not fill out this field. If they only appeared in one set, the set should be included.

Opening paragraph[]

The opening paragraph should have the title of the article in bold as well as a brief, short in-universe summary on the character. As the paragraph is in-universe, there mustn't be names of the episodes or out-universe descriptions of the character, such as that Kalmaar is the main villain of Season 14: Seabound. If a character happens to have a nickname, please put the nickname after the name of the character in the parentheses, like it is done on Killow's page. However, just significant nicknames belong here, not every nickname of the character. The others should be placed in the Trivia. The first sentence of the paragraph should explain the function of the character in the show and then describe the character's kinships, like it is done on Kai's page.

Required headings

Required headings[]

  • History
Main article: Ninjago Wiki:Manual of Style/Character History

This section should include the history of the character (in chronological order) and what the character did. When writing the history of a character, the episode that they appear in should have a sub-heading 1 with the rest of the text using the normal size text.

  • When a character's appearance in a flashback predates the series, the information should be placed at the appropriate time in the character's life, with (flashback) in the heading next to the episode name. However, if a flashback simply uses footage that was already seen in a previous episode, the episode does not need to be included in this section.
  • For characters whose background information is gained from many episodes rather than one episode in particular, or simply in contexts where the (flashback) format would not work as well, episode titles can be cited using the <ref> format rather than being used as the heading names, while the heading can have a more descriptive name like "Background" or "Early life", or simply "Prior to the series". See Dr. Julien's background for an example of this.

There are some characters like the ninja who have long histories; therefore, they have their own history page. Use the {{Main}} template to attach the character's history page. However, the history pages are used just for the main characters, so please do not create this type of page for the other characters.

  • Other appearances and mentions (if applicable)

This section should list the times the character has appeared indirectly or been mentioned. Note that most episodes mentioned in this section should be ones that aren't already part of the History section in some way. Also note that due to their prevalence in many episodes, Ninjago history mural appearances should not be listed in this section unless they are also accompanied by a mention or sound bite of the character.

  • Appearance (optional)

This section should explain the character's physical attributes and physical appearance such as their clothing, hair style, and anything else about the character.

  • Relationships

This section should contain all the relationships of the creature. Each relationship should be divided into the following sections:

    • Family - All the family members that the character is related with.
    • Allies - All the current friends and allies that the character might have.
    • Enemies - All the current enemies that the character might have.
  • Personality (optional)

This section should talk about the character's attitude and/or behavior throughout the series.

  • Weapons and abilities (optional)

This section should list all the weapons and abilities a character has. When writing this section, the words "Abilities" and "Weapons" should have a sub-heading 1 with the rest of the text using the normal size text. Within the "Abilities" section, you should list in bullet points any Elemental Powers the character has or any special talents. Within the "Weapons" section, list all weapons the character used.

  • Weaknesses (if applicable)

This section should list any weakness the character has.

  • In the Tournament app (if applicable)

If included in LEGO Ninjago: Tournament, this section should list the number of studs needed to purchase the character and any special abilities in the game.

  • Vehicles (if applicable)

This section is for vehicles belonging to this character. A character using a vehicle does not necessarily mean it will be listed here.

  • LEGO.com description(s) or Official description(s) (if applicable)

This section must be copied and pasted exactly from the LEGO.com website. Please do not edit the official description unless it was copied incorrectly or vandalized. If there is more than one description, sub-sections should be used to specify each description.

  • Appearances

This section should list all of the appearances a character appears in. This includes their physical appearance, pictures featuring them, murals, pixelated versions of them, flashbacks, cameos and mentions. If the character has no lines in the episode, it should be written after the name of episode in the parentheses. If the character appeared in the other way than physical appearance in the present, it should also be written after the name of the episode in the parentheses.

Set appearances are also listed here. Sets should be listed in ascending numerical order by the chronological appearance in which the minifigure design was released. The set appearances should be further categorized into [Boxed sets], [Polybags], [Magazine Gifts],[Books with Minifigures], and [Misc sets]. Further information on where other types of sets should be categorized can be found here.

  • Etymology (if applicable)

This section should explain the background of the character's name.

  • Behind the scenes (if applicable)

This section should contain information about the character's creation, inspiration, design process, or other similar information. Information regarding differences between the show and the products should be placed here.

  • Trivia (if applicable)

This section should contain any miscellaneous information which appeals to the reader.

  • Videos (if applicable)

Any videos the character appears in should go here. When adding videos, please make sure to refer to the Video policy to see what is acceptable.

  • Gallery

This section should contain images of the character. If a character happens to have a gallery page, please link it here. Furthermore, please make sure to check our Image policy when uploading images. Each gallery should be divided into the following sections:

    • Minifigures - If the character has a physical minifigure, these images should be included in this section.
    • Promotional media - All official promotional images depicting the character should be included in this section. These include CGI renders, season posters or gifs.
    • Concept art - All concept arts of the character should be placed in this section.
    • Design variants - All design variants of the character should be included in this section. These are images that include a character in various designs, such as a different outfit or appearance.
    • In Ninjago/Ninjago: Masters of Spinjitzu - All images from the TV series sorted into seasons with subsections should be included in this section.
    • In Ninjago: Dragons Rising - All images from the TV series sorted into seasons with subsections should be included in this section.
    • In other media - All other images depicting characters in books or video games should be included here.
  • References (if applicable)

If there are any citations made in the article, please make sure to put them here using the <references/> tag.
