This page will outline what is expected for each Creature page.

Title

Title[]

If the page is about a species, it should have the -s at the end of the title. However, if the page is about a specific creature, the title shouldn't be plural.

Introduction

Introduction[]

Infobox[]

After creating the page, please use the {{Character}} infobox and fill out the necessary information about the creature in the spaces provided.

  • color - This field should match the physical appearance of the creature. If the creature is currently unknown, please leave it grey.
  • image - This field should show an image of the creature from the Ninjago series. It is also possible to have an image from other official media if the creature has not appeared yet. Furthermore, the image may be cropped to show the creature.
  • affiliation - This field should list all the groups and/or businesses that the creature is officially a part of or a major ally of said group.
  • element - If the creature has an element, their Elemental Power should be listed. This does not include listing all of the Elemental Powers a creature has possessed. If the creature doesn't have an Elemental Power, please leave it blank.
  • home - The creature's native native habitat should go here.
  • occupations - This field should list all the jobs the creature had or currently has.
  • favweapon - This field should list all of the weapons used by the creature.
  • first appearance - This field lists the first appearance the creature makes. If the creature appeared in a set, it should be placed below. Meanwhile, if the creature never appears, the episode they were mentioned in can be listed.
  • latest appearance- This field should list the latest appearance of the creature. If the creature appeared in a set, it should be placed below. If the creature only appeared in one episode, please do not fill out this field. If the creature only appeared in one set, the set should be included.
  • status - This value should indicate a creature's current condition. For consistency’s sake, please use "Alive" if they're still alive and "Deceased" if they're dead. Other words to describe different situations will be discussed within the community.
  • family - The group that the creature belongs to should go in this field.
  • voice actor - If the creature happens to have a voice actor, it should go here. Otherwise, please don't fill in this field.

Quote[]

Another part of each creature page is the quote. The {{Quote}} template should go at the very top of the page. For the quote itself, it should describe the creature's history, role, personality, or a famous catchphrase. Moreover, the quote can be said from another character and doesn't have to come from the creature you're editing.

Opening paragraph[]

The first section should have the title of the article in bold as well as a brief, short info on the creature.

Required headings

Required headings[]

  • History

This section should include the history of the creature (in chronological order). This includes if the creature appears in an episode or is mentioned by a character.

  • Other appearances and mentions (if applicable)

This section should list the times the creature has appeared indirectly or been mentioned. Note that most episodes mentioned in this section should be ones that aren't already part of the History section in some way. Also note that due to their prevalence in many episodes, Ninjago history mural appearances should not be listed in this section unless they are also accompanied by a mention or sound bite of the creature.

  • Weapons and abilities (optional)

This section should list all of the fighting abilities the creature has as well as the weapons use when in combat.

  • Appearance (optional)

This section should explain the creature's physical attributes and physical appearance.

  • Relationships

This section should contain all the relationships of the creature. Each relationship should be divided into the following sections:

    • Family - All the family members that the creature is related with.
    • Allies - All the current friends and allies that the creature might have.
    • Enemies - All the current enemies that the creature might have.
  • Personality (optional)

This section should talk about the creature's attitude and/or behavior throughout the series.

  • LEGO.com description (if applicable)

This must be copied and pasted exactly from the LEGO.com website. Please do not edit the official description unless it was copied incorrectly or vandalized.

  • Appearances

This lists all of the appearances a creature appears in. This includes their physical appearance, pictures featuring them, murals, pixelated versions of them, flashbacks, cameos, mentions, etc.

  • Trivia

Any miscellaneous information which appeals to the reader.

  • Videos (if applicable)

Any videos the creature appears in should go here. When adding videos, please make sure to refer to the video policy to see what is acceptable.

  • Gallery

Pictures of the creature go here. Furthermore, please make sure to check our image policy when uploading images. Each gallery should be divided into the following sections:

    • In LEGO form/LEGO models - If the creature was released in the physical form, these images should be included in this section.
    • Concept art - All concept art of the creature should be placed in this section.
    • Promotional media - All official promotional images depicting the creature should be included in this section. These include CGI renders, season posters or gifs.
    • In Ninjago/Ninjago: Masters of Spinjitzu - All images from the TV series sorted into seasons with subsections should be included in this section.
    • In Ninjago: Dragons Rising - All images from the TV series sorted into seasons with subsections should be included in this section.
    • In other media - All other images depicting creatures in books or video games should be included here.
  • References (if applicable)

If there are any citations made in the article, please make sure to put them here using the <references/> tag.
