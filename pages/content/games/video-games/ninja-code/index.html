Ninja Code was a Rebooted-themed web game added to the Cartoon Network website in 2014. The game was a scrolling game where your character moved on a set path, with fifteen levels and three boss fights. Points were earned primarily through collecting orbs, defeating enemies, performing combos, as well as bonus points.[1]
