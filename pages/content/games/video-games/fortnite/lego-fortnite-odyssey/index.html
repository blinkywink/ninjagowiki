Overview

"Not even close!"
This topic is considered non-canon because it is set in a world that extends beyond the Ninjago franchise.

LEGO Fortnite Odyssey (formerly known simply as LEGO Fortnite) is a survival crafting game within Fortnite. So far, it had two Ninjago-themed updates: Rise of the Ninja, which released on December 11, 2025, and Embers of Chaos, which released on April 16, 2026.
