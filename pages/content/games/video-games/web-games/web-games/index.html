Overview

"Not even close!"
This topic is considered non-canon because they are only loosely based on the TV series.

Web games are games released on LEGO.com[1], Cartoon Network and Toggo.de[2] for German games.

These games exist to advertise the sets from various waves. Many of them have mobile apps as well. The web games were formerly listed on Cartoon Network's website but have since been removed. Web games that have been removed from LEGO.com can still be played on IOS devices if you added the link to home screen before its discontinuation or if you have the app version of that game (if available).

As some of the games are exclusively in German, the titles will be translated.
