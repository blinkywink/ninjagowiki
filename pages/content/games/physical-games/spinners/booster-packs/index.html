Overview

Booster Packs were a subtheme of Ninjago sets released in 2012. They were an inexpensive way to add defenses, weapons, and minifigures to one's Ninjago Spinners collection. Each Booster Pack retailed for $4.99 US, with the exception of Kendo Jay, which was a promotional item with LEGO's Shop at Home website. Their packages each had a small, clear window to see some of the parts included.

Aside from the Kendo Jay promotional set, each set contained a single Minifigure, as well as three Minifigure weapons, three defenses for the base of a spinner, and a height addition piece. A set of game cards also was included.

Kendo Jay's Booster Pack was packaged like a polybag and included extra weapons and an extra spinner crown.
