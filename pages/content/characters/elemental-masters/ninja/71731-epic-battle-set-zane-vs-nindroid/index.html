Overview

71731 Epic Battle Set - Zane vs. Nindroid is a Ninjago: Legacy Wave 4 set that was released on January 2, 2021. It includes Epic Battle Zane and a Legacy Nindroid Drone, a shrine, a "Spinjitzu Battle Platform," and extra weapons.

LEGO.com description

LEGO.com description[]

This impressive Epic Battle Set – Zane vs. Nindroid (71731) lets kids create their own thrilling fights between ninja Zane and a Nindroid robot warrior. The high-action playset also features a brick-built Nindroid factory and spinning battle toy for NINJAGO® fans to include in their exciting duels.

Trivia

Trivia[]

  • Epic Battle Zane is exclusive to this set.
  • This is the first set to include Zane's post-movie hair piece in silver. His original silver hair piece appeared in 70588 Titanium Ninja Tumbler and 70591 Kryptarium Prison Breakout, making this the third non-polybag set to feature Zane with silver hair.
    • This is the first set of the Legacy sub-theme that includes Zane's silver head, which was first introduced in the Sons of Garmadon wave.
  • Michael Knap sees Zane's design in this set as "a different suit/skin. I imagine he has a variety of different ones he can choose from depending on the situation."[2]
  • The new transparent weapon packets resemble active golden weapons
