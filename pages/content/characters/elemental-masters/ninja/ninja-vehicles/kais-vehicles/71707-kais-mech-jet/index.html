Overview

Not to be confused with the actual Mech Jet.

71707 Kai's Mech Jet is a 2-in-1 Ninjago - Prime Empire set that was released on January 2, 2020. It includes Digi Kai, Richie, the Orange Key-Tana within a loot box, Richie's hoverboard and the Mech Jet, which can be built into either the Jet form or the Mech form.

Trivia

Trivia[]

  • This is the first Ninjago set which can be built in two different ways, similar to another LEGO subtheme of a line named LEGO Creator, where its signature thing is "3 in 1", which incorporates several different builds within a set.
  • This is the cheapest set that Richie and the Orange Key-Tana appears in.
  • Although there were three prime controllers in 71709 Jay and Lloyd's Velocity Racers (one for the kusarigama, one for the flying speeder and another for the sword) this set only includes two. (One for the handle on the jet/weapon holster, and the other one for Richie's double bladed weapon.)
  • The jet form of this set was first seen in "Racer Seven," and the mech form was first seen in "The Speedway Five-Billion."
  • That is the third time Kai had a mech and a jet, the second being The Movie Version of the fire mech/Legacy Version of Kai Fighter and the first being the fire mech/Kai Fighter.
  • In some of the images there are also two extra health boards, one orange and one fluorescent green, but the actual set does not for reasons that are unknown.
