Overview

This article is about the legacy set. For the original set, see 70754 Jay's ElectroMech. For the actual vehicle, see ElectroMech.

71740 Jay's Electro Mech is a Ninjago: Legacy Wave 4 4+ set that was released on March 1, 2021. It includes Legacy (sleeveless) Jay, Legacy Eyezor, the ElectroMech, Eyezor's quad bike and a small rock with a spider.

LEGO.com description

LEGO.com description[]

Kids can develop their building skills and play out fun scenes from season 4 of the LEGO® NINJAGO® TV series with Jay’s Electro Mech (71740). Featuring a posable mech, ninja car, spider toy, and a golden-sword display, kids can enjoy hours of ninja adventures.

Learn to build with LEGO® NINJAGO®
This cool ninja toy is specially designed to give young builders aged 4 and up a brilliant play experience. Inside the box, each bag of bricks has a complete model and character to build so kids can quickly get the action underway. There is also a Starter Brick to provide a partly constructed base to start building.

Fun for all the family
LEGO® 4+ sets are the perfect way for adults to enjoy building with kids. It’s quick and easy to get started – as well as a step-by-step paper guide in the box, this set comes with Instructions PLUS on the LEGO Building Instructions app. This interactive guide includes zoom, ghost and rotate tools for children to get the most from the building process.

Trivia

Trivia[]

  • This set is a 4+ Legacy remake of the 2015 set 70754 Jay's ElectroMech from Tournament of Elements. It differs greatly from the original version.
  • The Legacy (sleeveless) Jay included is unique, sporting the Legacy (dragon) hood, as opposed to the half mask.
