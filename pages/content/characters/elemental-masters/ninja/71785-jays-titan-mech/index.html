Overview

71785 Jay's Titan Mech is a Ninjago: Core set that was released on January 1, 2023. This set includes Jay and Nya in their Core suits, a Pixal Bot, the Bone King, a Bone Knight, a Bone Hunter, Jay's Titan Mech, and a wagon.

Designer's notes

Designer's notes[]

"Another mech, wouldn't you know it. This Ninjago Core set was developed in tandem with the new Dragons Rising show, which is why it was lucky to get a couple of seconds of fame in the first episode.

This mech is very different from a lot of the other ones I did. Normally, I build stuff chunky and angular, but for this we wanted to go for a sleek, slowing and organic aesthetic (90s anime). Getting the hips to be that close together was a real challenge as was making an arm that would be strong enough to hold up the biggest sword we have every put on a Ninjago mech. I am really happy with how it turned out and with how relatively simple the build ended up being. It was a fun model to design.

For the conflict I was excited to resurrect the old Vikings projectile launch function. It is not as powerful, but I think it is still fun and hopefully inspiring the next generation with the same fun functions I grew up with."[2]

Trivia

Trivia[]

  • Some boxes refer to the Pixal Bot as a Wu Bot.
  • The build was a challenge to create; it was more streamlined than other large mechs, and the joints had to be kept posable and stable at the same time.[3]
    • The mech features the largest sword for any Ninjago mech ever.[3] Design Director Sven Kahl encouraged Niek van Slagmaat to "go crazy" with the sword.[4]
    • The set was mostly inspired by 90s mechas.[5]
